# CTDR Los Reyunos — maqueta del sitio web

Maqueta estática del sitio del Centro Tecnológico de Desarrollo Regional Los Reyunos (UTN Facultad Regional San Rafael).

- `index.html` — la página completa (HTML + CSS + JS, sin build). Abrirla directo en el navegador.
- `assets/img/` — logo UTN San Rafael y fotos tomadas del sitio oficial reyunos.utn.edu.ar.
- `assets/map/` — teselas de OpenStreetMap (© colaboradores de OpenStreetMap) para el mapa de contacto.
- `ESTRUCTURA BASE web CTDR LOS REYUNOS.xlsx` — esquema original de secciones.

Lo marcado "pendiente" en la página (textos, detalle del GEDT, email, testimonios, logos de instituciones) falta definir.
Las fotos son de terceros: confirmar con el centro que se pueden reutilizar antes de publicar el sitio definitivo.
